# NAT-210

Benchmark with 210 reference article to evaluate a search for alternative methods to animal experiments.

- **na-210.json** list of reference article, alternative emthods and the simiilar articles, as ranked in PubMed (as of August/26)
- **na-210-smafira.json** list of reference article and the simiilar articles, as ranked by SMAFIRA (as of August/26)
